# DTSS: Drift-aware Text Stream System

This repository contains the code used for the thesis experiments on **Drift-aware Text Stream Systems (DTSS)**. DTSS detects concept drift in evolving text streams, assigns windows to recurring semantic states, and evaluates whether the discovered states can support downstream state-topic summarization and retrieval-cache feasibility analysis.

The code in this submission corresponds to the final experimental pipeline used in the thesis. Large raw datasets, model caches, processed stream caches, and full output folders are intentionally not included.

## 4. Running One DTSS Experiment

The main entry point is:

```bash
python src/run.py --dataset <DATASET_NAME> --drift_mode <DETECTOR> --gpu <GPU_ID>
```
to run the code with enabled rag part use 
```
python src/run.py --dataset <DATASET_NAME> --drift_mode <DETECTOR> --gpu <GPU_ID> --enable_rag
```
Example:

```bash
python src/run.py --dataset MultiHopRAGStreamSim --drift_mode ks_alibi --gpu 0
```

Supported detector modes used in the thesis include:

```text
ks_alibi
mmd
energy
```

The exact window lengths, detector parameters, state-assignment settings, and dataset caps are defined in `configuration/config.json`.

## 8. Evaluation Overview

The thesis evaluates DTSS at three levels:

1. **Event-level drift detection**  
   Measures whether true drift events are detected within a tolerance window while controlling false alarms and alarm timing.

2. **State modeling**  
   Evaluates whether drift-triggered state assignment captures new and recurring semantic contexts. The thesis compares cosine-based state assignment with KLD-based assignment.

3. **Downstream feasibility analysis**  
   Uses `MultiHopRAGStreamSim` to inspect whether discovered states can support state-topic summarization and future retrieval-cache construction.

The main detector selection is based on practical event-level behavior, especially event F1-score and NAB-style timing score. Shifted AUROC is used only as a diagnostic sensitivity check for temporal score-label misalignment.

## 10. Cleaning Before Submission

Before creating the final zip file, remove Python cache files:

```bash
find . -type d -name "__pycache__" -prune -exec rm -rf {} +
find . -name "*.pyc" -delete
find . -type d -name ".ipynb_checkpoints" -prune -exec rm -rf {} +
```

Then create a zip file from the clean submission folder:

```bash
zip -r DTSS_code_submission.zip DTSS_code_submission \
  -x "*/__pycache__/*" \
  -x "*.pyc" \
  -x "*/output/*" \
  -x "*/data/processed_streams/*" \
  -x "*/.ipynb_checkpoints/*" \
  -x "*/.DS_Store"
```
